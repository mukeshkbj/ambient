# Scan report — 2026-09-16

First pass of the new performance / code-quality / dead-code toolchain.

## Toolchain added

- **ESLint** (`eslint`, `typescript-eslint`, `@eslint/js`) — flat config at `eslint.config.ts`; type-aware rules (`no-floating-promises`, `no-misused-promises`, unsafe `String()`/member rules) over `src/`, `scripts/`, `test/`. Test files get relaxed `unbound-method` (vi.fn mocks are the norm).
- **Knip** — `knip.json`; entries `scripts/*.ts`, `infra/app.ts`; project graph covers `src/`, `scripts/`, `test/`, `infra/` so the CDK deps resolve to real usage instead of being suppressed.
- **`pnpm scan`** — `typecheck && lint && knip && test`.
- **`scripts/latency.ts`** — now samples per tool (`LATENCY_TOOLS`, default `list_conversations,get_work`) and reports p50/p95/max per operation.
